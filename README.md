# Grok Build Desktop

インストール済みの Grok Build と、`grok --permission-mode default agent --no-leader stdio` の ACP で会話する Windows アプリです。会話の正本は Grok のセッションに残り、このアプリはそれを写し取りません。

現在の開発βは v0.0.4 です。Windows 用インストーラは、このリポジトリの prerelease にあります。v0.0.2 以降は、設定の「このアプリ」から更新できます。

## 起動

```powershell
npm install
npm run tauri dev
```

Grok にログインしていないときは、画面の「ログイン」から `grok login` を開きます。

## 画面

左に検索、新規チャット、新規プロジェクト、登録したフォルダがあります。選んだフォルダの会話だけを罫線で出し、三角の印で畳めます。開閉には動きが付きます。設定の「開閉の動きを出す」で切れます。

セッションが開いていないときは、会話欄の中央でプロジェクトを選びます。選んでメッセージを送ると、そのフォルダの新しいセッションになります。

設定は左下から開きます。ウィンドウの大きさは固定で、分類は表示、自動承認、使用量、コマンド一覧、このアプリです。
