# Grok Build Desktop

インストール済みの Grok Build と、`grok --permission-mode default agent --no-leader stdio` の ACP で会話する Windows アプリです。会話の正本は Grok のセッションに残り、このアプリはそれを写し取りません。

現在の開発βは v0.0.5 です。Windows 用インストーラは、このリポジトリの prerelease にあります。v0.0.2 以降は、設定の「このアプリ」から更新できます。

## 起動

```powershell
npm install
npm run tauri dev
```

Grok にログインしていないときは、画面の「ログイン」から `grok login` を開きます。

## 画面

左に検索、新規チャット、新規プロジェクト、登録したフォルダがあります。選んだフォルダの会話だけを罫線で出し、三角の印で畳めます。開閉には動きが付きます。設定の「開閉の動きを出す」で切れます。

セッションが開いていないときは、会話欄の中央でプロジェクトを選びます。選んでメッセージを送ると、そのフォルダの新しいセッションになります。

設定は左下から開きます。ウィンドウの大きさは固定で、分類は表示、自動承認、エージェント、使用量、コマンド一覧、このアプリです。

## 自律実行

送信欄の下の「実行」を「自律実行」にして目的を送ると、司令塔の Grok が作業を分け、設定の「エージェント」に登録した CLI（Claude Code、Codex、Grok、Antigravity、カスタム）に順に指示を出します。各ステップの理由、渡したプロンプト、結果、git の差分が会話欄に並び、「ログ」で CLI の生の出力を追えます。

始められるのは、git のリポジトリで 1 つ以上のコミットがあるフォルダだけです。判断の回数の上限（初期値 10 回）か、同じ失敗が 2 回続いたところで一時停止します。「ループを止める」を押すと、動いている CLI をすぐに終了します。

各 CLI の既定の引数は、確認なしの全権限を与えないものにしてあります。`--dangerously-skip-permissions` などの危険なフラグは、そのエージェントの「危険なフラグを許可」をオンにしない限り使えません。各 CLI へのログインは、それぞれの CLI で済ませておきます。
